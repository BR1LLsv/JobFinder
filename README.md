# JobFinder

## Что делает этот проект
JobFinder — это веб-приложение для работы с вакансиями. Оно автоматически загружает свежие предложения работы с сервиса Jooble через API, а также предоставляет удобный интерфейс для поиска, просмотра, добавления, редактирования и удаления вакансий вручную.

## В чём смысл проекта
Смысл проекта — автоматизировать сбор актуальных вакансий с внешних платформ и объединить их в единой базовой системе. Это позволяет быстро находить нужные предложения по ключевым словам и легко управлять объявлениями через простой и легкий веб-интерфейс.
